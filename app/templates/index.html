      API 参考 / 后端契约

      全部接口在 /api/v1 下，统一返回信封： {code, status, data}（失败时是 {code, status, message}）。

      方法路径说明
      GET/api/v1/健康检查
      GET/api/v1/example/list示例知识库列表
      POST/api/v1/example/load?name=载入示例（替换知识库并清空工作记忆）
      POST/api/v1/engine/init清空知识库 + 工作记忆
      POST/api/v1/engine/reset复位推理状态（保留事实与知识库）
      POST/api/v1/engine/run后台运行到不动点
      POST/api/v1/engine/pause暂停后台推理
      POST/api/v1/engine/status运行状态 / 迭代数 / 停止原因
      POST/api/v1/engine/step单步触发一条规则
      GET/api/v1/engine/facts列出事实
      POST/api/v1/engine/facts断言事实 {name, value}
      GET / DELETE/api/v1/engine/facts/<name>查询 / 删除单条事实
      DELETE/api/v1/engine/facts清空事实

      单步的返回形状：规则触发时 data 是 {fired: true, name, conditions, conclusion, priority, iterations}， 其中 conditions 是条件函数名列表（例如 has_link_down）， conclusion 是 {name, value}； 没有规则可触发时是 {fired: false, stop_reason, iterations}。

      注意：POST /engine/run 与 POST /engine/pause 在状态不匹配时（已在运行 / 未在运行）会抛 RuntimeError，被 auto_handle_exception 收敛成 500 / code -1；非 debug 模式下 message 还会被抹成 “Unknown error”。所以「暂停」按钮只在引擎运行时可用。

      事实的 value 必须可哈希（不能是对象或数组），省略时后端默认 true。 事实名里带 / 虽然能写进工作记忆，但 /engine/facts/<name> 路由匹配不到斜杠，之后无法单条查询或删除，因此前端直接禁止。

      未注册的路径不经过 auto_handle_exception，Flask 会直接返回 HTML 404； 控制台会把它显示为「服务端返回了非 JSON 响应」。
